### 逐级说明

| 级 | 元件 | 我的判断 |
|---|---|---|
| 电源入口 | `V+` → `D1`(1N4007) → `VCC` | 反接保护二极管，VCC ≈ 9 − 0.7 ≈ **8.3V** |
| 电源指示 | `VCC → R10(4.7k) → [C9(100µF) 到地] → R9(4.7k) → LED1 → GND` | LED 电流 ≈ (8.3−1.8)/9.4k ≈ **0.7mA**（很暗）；C9 让这节点对音频是干净的 |
| 输入 | `IR`(输入插头 tip) → `SWI`(旁路开关) → `C1`(10nF) → Q1 基极 | 隔直 + 与 ADJST 构成高通 |
| 偏置 | `ADJST` 1M 微调，VCC↔GND，抽头→Q1 基极 | 手调 Q1 基极直流 = 整机工作点 |
| 缓冲 | `Q1` BC547/549 NPN，C=VCC，B=基极，E→R2(10k)+R5(10k) | **射极跟随器**，输入阻抗高 |
| 增益级 | `Q2`/`Q3` NPN 差分对（发射极共接 → `R11` 10k → GND），`Q3` 基极 = `OPI-` | **离散运放的差分输入级** |
| 输出级 | `Q2` 集电极 → `Q4`(BC559 PNP) 基极；`Q4` 射极 = VCC，集电极 = `OPO`；`R12`(2.2k) OPO→GND | **Sziklai 复合管**构成的高增益反相输出，R12 是负载/直流回路 |
| 反馈 | `H1`(FUZZ) 2/3 脚短接 → 当**可变电阻**用，接 `OPO` ↔ `OPI-`；`OPI-` 经 `C2`(47nF)+`R4`(4.7k) 到地 | **非反相放大器**，AC 增益 ≈ 1 + H1/(R4 + 1/sC2)，**DC 增益 = 1**（C2 隔直）—— 典型的踏板失真增益级 |
| 削波 | `OPO` → `C3`(1µF) → `R6`(10k) → 节点 → `D2`(1N4007)∥`LED2` 到地，`C4`(1nF) 到地 | 硬削波 + 一阶低通（约 **1/(2π·R6·C4) ≈ 16kHz**，R6-C4 构成） |
| 音量 | 削波后节点 → `H2`(LEVEL) → `FXOUT` → `SWO` → `OUT` | 标准音量电位器 |
| 光控衰减 | `R1`(LDR) 接 `FXOUT` ↔ GND，与 H2 构成分压 | 输出端光控衰减 |
| 旁路 | `SWI`/`SWO` 两个 2 脚开关 | 机械 true-bypass |

## 2. ⚠️ 对不上的地方（必须先确认）

### Q1. 这份网表和你说过的器件不一致

你说「二极管用 **1N4148**，运放用 **OP07**」。但这份网表里：

- **没有任何运放**，运放位置是 4 只分立三极管（Q2/Q3/Q4 + Q1 缓冲）搭的"分立运放"
- **没有 1N4148**，只有 **1N4007**（D1 反接保护 + D2 削波）+ 2 只 LED

→ 这是**另一个版本**、还是你打算把分立运放换成 OP07、把 1N4007 换成 1N4148？
（这个答案决定我按哪个电路建模，不能猜。）

### Q2. LED2 与 1N4007 直接并联，LED2 理论上永远不会亮

`$1N3277` 节点上：`D2.1 → GND`、`LED2.1 → GND`，两者**同向并联**。
1N4007 的 Vf ≈ 0.7V，红色 LED 的 Vf ≈ 1.8V —— D2 会先把电压钳在 0.7V，
**LED2 根本达不到导通电压**。

那么"LDR（R1）到底被谁照亮"就成问题了：

- 如果光源是 **LED2**（音频调制）→ 现在这个接法不会有任何光 → 压缩功能不存在
- 如果光源是 **LED1**（电源指示，恒定）→ 那 R1 只是恒定衰减，不是压缩

可能的原因：EasyEDA 里 **LED 符号与 Diode 符号的 pin1/pin2 约定不同**（一个 pin1 是阳极、另一个是阴极），
导致网表看起来"同向"实际"反向"。**需要原理图才能判定。**

### Q3. 元件值有冲突（*PART* 段的库名 vs 属性里的 Name）

| 元件 | 库里的名字 | 属性里的 Name | 影响 |
|---|---|---|---|
| C1 | 4n7 | **10nF** | 输入高通拐点差 4 倍 |
| C2 | 4n7 | **47nF** | 反馈低频拐点 |
| C3 | 4n7 | **1µF** | 削波前耦合，影响低频 |
| C4 | 4n7 | **1nF** | 削波后低通 16k → 34k |
| C9 | 10u | **100µF** | 电源指示 RC |
| Q1/Q2/Q3 | BC547B | **BC549C** | hFE 差 2~3 倍，直接影响失真特性 |
| Q4 | BC559CTA | **BC559C** | 同上 |
| ADJST | 卧式/蓝白色 | **1M** | 偏置范围 |

我的默认取法：**以属性里的 Name 为准**（那才是你填的 BOM 值）。请确认。

### Q4. 电位器阻值缺失

`H1`(FUZZ)、`H2`(LEVEL) 只有封装 `POT_5.04` 和立创编号，**没有阻值**。

- FUZZ 电位器决定最大增益（≈ 1 + H1/R4，R4=4.7k）→ 若是 500k，最大增益 ≈ 107×，很关键
- 还需要 **taper**（A 对数 / B 线性 / C 反对数）

### Q5. LDR 参数

`R1` = LDR，没有型号。需要：亮阻/暗阻（如 GL5528：亮 ~10k，暗 ~1M）、响应时间。

### Q6. 引脚编号语义

网表里 `Q1.1/2/3` 是**封装焊盘号**。我按 `1=C, 2=B, 3=E` 解读（BC547/BC559 的常规 TO-92 引脚），
这个假设自洽（Q4 的 3 脚接 VCC = PNP 射极，符合 Sziklai 结构），但请核一下。

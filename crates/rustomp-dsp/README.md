# rustomp-dsp

电路建模的 DSP 核心。所有实现都以 **ngspice 基线**为准，并且基线是**可复现的对拍测试**。

## 已验证：fakedist v1

```bash
cargo test -p rustomp-dsp --release --test baseline -- --nocapture
```

对照 `circuits/fakedist/baseline.txt`（ngspice-47，电位器 50%）：

| 直流工作点 | 4.49999 V | 4.50000 V | 0.01 mV |
| DC 增益 | 1.0000 | 1.0000 | — |
| 频响峰值 | +28.30 dB @ 2 kHz | +28.29 dB | +0.01 dB |
| 频响 50 Hz – 10 kHz | — | — | **≤ 0.31 dB** |

| h2 / h3 / h4 / h5 | 3.92 / 22.49 / 2.43 / 11.98 % | 3.92 / 22.47 / 2.43 / 11.96 % | ≤0.03 pp |
| h6 / h7 / h8 / h9 | 1.84 / 7.70 / 1.48 / 5.40 % | 1.84 / 7.67 / 1.48 / 5.37 % | ≤0.03 pp |

> 参考值取自 **1 µs 步长（1 MHz）** 的瞬态波形 + 同一套 DFT。

## 设计要点

| 部分 | 做法 |
|---|---|
| 线性储能元件（C1/C2/C3） | 梯形法伴随模型 `i[n] = (2C/T)(v[n]−v[n−1]) − i[n−1]`；与 WDF 单端口（`R=T/2C`，`b[n]=a[n−1]`）是同一个差分方程 |
| 非线性反馈节点（IN−） | **1 维**牛顿：未知量只有 `v_IN−`，实测 2~4 步收敛 |
| 运放 | 单极点宏模型（A0=5e5、GBW=0.6 MHz）+ 梯形离散，更新式**代进节点方程**求解，**环内无延迟** |
| 非线性器件 | 1N4148 的 `Is / N / Rs`，Rs 用内层牛顿解出结电压 |
| 电位器 | 线性 taper；GAIN = 变阻器（0–500k），LEVEL = 分压比 |

### 踩过的坑（都写成了测试）

1. **两只二极管串联时发射系数也要翻倍**，不是只翻 Rs：
   `i = Is·(exp(u/(2·N·Vt)) − 1)`。只翻 Rs 会让串联支路提前导通，
   波形变得过于对称（h2 从 3.9% 掉到 0.00%），THD 从 27.6% 掉到 26.4%。
2. **ngspice `-r` 保存全程会爆内存**：3 s × 1 µs = 300 万点 ≈ 2.4 GB。
   用 `.tran step stop start` 只保存尾窗（3 MB）。
3. **这个电路的直流恢复时间常数 ≈ 0.5 s**（C3 1µF × 电平电位器 500k）：
   测 THD 前必须跑够 3 s，否则输出还带着非对称削波充出来的直流。

## 过采样（必需，不只是"为了好听"）

`Engine` = `Fakedist`(4×fs) + `Oversampler4x`（64 抽头 Kaiser-windowed sinc 多相 FIR，
通带 0–10 kHz 平坦，22 kHz 处 >−20 dB，群延迟 15 个基带样本）。

**直接以 48 kHz 运行电路会失效**（`cargo run --example os_probe`）：

| 过采样 | 电路 fs | 1 kHz | 3 kHz | 8 kHz |
|---|---|---|---|---|
| 1x | 48k | 0.4792 ✓ | **0.0000 失效** | **0.0000 失效** |
| 2x | 96k | 0.4791 ✓ | 0.4999 ✓ | 0.3130 偏低 |
| **4x** | **192k** | 0.4791 ✓ | 0.5000 ✓ | 0.4998 ✓ |
| 8x | 384k | 0.4791 ✓ | 0.5001 ✓ | 0.4998 ✓ |

原因是运放的梯形离散把闭环极点（≈10.8 kHz）放在离 Nyquist 太近的位置，
48 kHz 下隐含方程欠解析，牛顿会收敛到错误的解（输出被钳在供电轨）。
→ 4x 是**正确性下限**，8x 与 4x 的差别已在 0.1% 以内。

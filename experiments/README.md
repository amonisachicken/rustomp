# experiments —— 归档的一次性验证代码

结论与数据都记录在仓库根目录的 `DEVLOG.md`。

| 目录 | 内容 | 对应 DEVLOG |
|---|---|---|
| `e1_wdf_diode_clipper/` | 最早的可行性验证 spike：WDF 二极管削波级 + 牛顿法 + 吞吐量基准 | E1 |
| `v1-easyeda-pcb/` | （历史）从 EasyEDA 的 PCB ASCII 导出反推电路的脚本与结果；该电路已被 `plugins/sparklin-drive` 取代 | E7 |

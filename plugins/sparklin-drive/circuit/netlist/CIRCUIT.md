## 1. 这个电路是什么

**单电源 9V、OP07 单运放、反馈环内非对称二极管削波**的失真/法兹。

```
        (V+ = 9V)  ── R2 47k ──┬── R3 47k ── GND      (4.5V 偏置)
                              └── R4 470k ── IN+
IN ──C1 4.7n──► IN+ ── OP07 ── OUT ──C3 1µF──► P2 500k(LEVEL) ──► 输出
                 │                 │
        R5 4.7k ──┴── C2 47n      └──► P1 500k (2/3 短接 = 可变电阻)
                 │                              │
                IN- ◄───────────────────────────┘
                 │
                 └── 削波环：D1(1 只) ∥ D2+D3(2 只串联，反向)
```

### 器件表（来自 netlist.cir）

| 元件 | 值 | 作用 |
|---|---|---|
| U1 | OP07A（breadspice `models.lib` 的完整 `.SUBCKT`） | 主放大 + 削波 |
| B1 | 9 V | 单电源 |
| R2 / R3 | 47k / 47k | 4.5V 偏置分压 |
| R4 | 470k | IN+ 偏置电阻（同时与 C1 构成输入高通） |
| C1 | 4.7 nF | 输入隔直（fc ≈ 1/(2π·470k·4.7n) ≈ **72 Hz**） |
| R5 | 4.7 kΩ | 反馈网络的下臂电阻 |
| C2 | 47 nF | 与 R5 串联到地 → 低频转折 1/(2π·4.7k·47n) ≈ **720 Hz**，DC 增益 = 1 |
| P1 | 500 kΩ（网表里 50% = 250k+250k） | **增益电位器**：Zf |
| D1, D2, D3 | 1N4148 ×3 | **反馈环内的非对称削波环** |
| C3 | 1 µF | 输出隔直 |
| P2 | 500 kΩ（50% = 250k/250k） | **音量电位器** |

## 2. 三个关键设计点（建模时不能搞错）

### 2.1 削波在**反馈环里**，而且是 **1 只 vs 2 只** 的非对称环

三只二极管接成闭环：`OUT(t1L) →D1→ IN-(t10L) →D3→ t5L →D2→ OUT(t1L)`。

等价于在 `OUT` 与 `IN-`（即反馈电阻 P1 的两端）之间并上：

- 一个方向：**1 只**二极管（Vf ≈ 0.7 V）
- 另一个方向：**2 只串联**（Vf ≈ 1.4 V）

所以是**非对称软削波**（TS/RAT 的做法，而非对地硬削波）：

- 削波发生在反馈环里 → 输出被钳制、但**增益本身被压缩**（"软"、"压缩感"）
- 1 vs 2 的不对称 → 产生**偶次谐波** + **直流偏移**（见 2.3）

仿真验证（`baseline.txt`）：`v(t5L)`（两只串联的中点）在 3.881 ~ 4.910 V 之间摆动
→ 证明"两只串联"这一支确实在导通，不是摆设。

### 2.2 增益

非反相放大：`A = 1 + P1 / (R5 + 1/(s·C2))`

- 中频最大：`1 + 500k/4.7k ≈ 107×（+40.6 dB）`（电位器拧到最大时）
- 网表默认 50%：`1 + 250k/4.7k ≈ 54×`，扣掉音量电位器的 1/2 分压 → 实测**峰值 +28.4 dB**
- DC 增益 = 1（C2 隔直）
- 高频滚降来自 OP07 本身（GBW ≈ 0.6 MHz，压摆率 ≈ 0.25 V/µs）—— **这就是 OP07 的音色**

### 2.3 C3 × 音量电位器 ≈ **0.5 s** 的直流恢复（blocking distortion）

非对称削波会在 C3 上充出直流，而放电回路是 `C3(1µF) × (P2 的 500k)` ≈ **0.5 s**。

后果：

- 这是"**阻塞失真 / 窒息感**"的来源，是音色的一部分，**必须建模**（不能只做对称削波）
- 测量时必须跑足够久才能到稳态：只跑到 40 ms 时输出均值是 **−0.089 V**（还在充电），
  跑到 3 s 才是 **+0.00001 V**。
  → `scripts/sim-baseline.sh` 默认 `.tran 5u 3 2.98`（跑 3 s，只保存最后 20 ms），
    约 6 秒仿真时间、3 MB rawfile；若保存全程，3 s 的 rawfile 会到 **2.4 GB**。
